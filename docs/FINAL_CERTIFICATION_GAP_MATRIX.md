## External Certification Prerequisites

1. **GitHub Branch Protection Activation**: Requires GitHub Repository Admin personal access token with `repo` scope to execute `scripts/setup-branch-protection.sh` and satisfy `scripts/verify-branch-protection.sh`.
2. **Container Registry & Signing Credentials**: Requires `GHCR_TOKEN` / `COSIGN_PRIVATE_KEY` secrets configured in GitHub Actions to execute image push, signing, and provenance publication in `.github/workflows/release.yml`.
3. **Dedicated Full-Scale Load Infrastructure**: GitHub-hosted runners have CPU/RAM limits (2 vCPU, 7GB RAM). Full 15-minute 500 RPS benchmark against 500,000 students should be triggered via `workflow_dispatch` on a self-hosted runner or dedicated load environment (8+ vCPU, 16GB RAM PostgreSQL/Redis instance).
